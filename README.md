# World Travel Blog 🌍

Ein Gruppenprojekt für die Frontend Weiterbildung bei der Developer Akademie

## 📖 About
Der **World Travel Blog** zeigt 3 individuelle Reiseziele, kuratiert von drei Teammitgliedern.  
Jede Seite präsentiert ein Land mit persönlicher Perspektive – Kultur, Kulinarik und Must-See Sights.

## ✅ Features
| Seite         | Inhalt                                 
|-------        |--------                                
| **Index**     | Highlights, FAQ, Contact (gemeinsam)   
| **Jin**       | 🇰🇷 Seoul & Beyond     
| **Neelima**   | 🇮🇳 Incredible India 
| **Patrick**   | 🇩🇪 Scenic Germany

## 🛠 Tech Stack
- HTML
- CSS (Fonts, Variables, Standard-Styles)

## ▶️ Setup / Ausführen
1. Repo klonen: `git clone <repo-url>`
2. `index.html` in VS Code öffnen
3. Live Server starten

## 🌿 Git Workflow
- Branch pro Person: `jin`, `neelima`, `patrick`
- Änderungen per Pull Request, Review durch Team
- Kein direktes Pushen auf `main`
